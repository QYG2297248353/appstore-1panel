# Peach

本地优先的视频元数据刮削与媒体管理工具，通过浏览器管理，适合单人 VPS 与 NAS 使用。

## 简介

Peach 是一个自托管的媒体库管理与刮削工具：扫描本地磁盘、SMB 共享与已挂载的网盘目录，识别视频番号、读取 NFO 并补全标题、演员、片商与封面，在浏览器中浏览、播放与追更。

元数据与观看历史全部保存在本地，不依赖云端账号。

> Peach 不提供视频资源，请仅管理你拥有或获得授权的内容。

## 特性

- **元数据刮削**：识别视频番号，读取 NFO，从多个来源补全标题、演员、片商与封面，并保留你的手动修改
- **本地与云端媒体库**：同时浏览本地磁盘、SMB 共享、已挂载网盘与 PikPak 媒体库
- **播放与历史**：网页播放器与外部播放器、字幕、倍速、旋转、断点续播与时间轴预览
- **关注与发现**：跟踪演员与创作者更新，发现作品并维护想看清单
- **云下载**：按番号搜索或提交磁力链接，完成后自动整理入库
- **媒体库管理**：标签、重复项、版本与分集管理，可按演员永久删除影片并保留人物资料
- **任务中心**：暂停、恢复或取消后台任务，查看 CPU、GPU 与下载活动

## 部署说明

### 数据与媒体目录

| 挂载路径 | 用途 |
| --- | --- |
| `${PEACH_DATA_PATH}/data` → `/data` | 配置、SQLite 数据库、凭据与图片缓存，升级或重建容器时保留 |
| `${PEACH_MEDIA_PATH}` → `/media` | 实际媒体文件目录，可挂载已有媒体库 |

`/data` 必须持久化，删除后配置与数据库会丢失。媒体目录默认可直接读写，整理、移动与删除影片需要写权限。

Peach 容器以 UID 1000 运行，安装时会自动将数据目录授权给该用户；如挂载已有媒体目录后出现读取失败，请确认目录对 UID 1000 可读。

### 首次设置

容器启动后用浏览器打开 `http://<服务器 IP>:<端口>`（默认 8900），首次打开会进入设置向导：确认媒体目录、设置访问密码或选择免登录、选择代理并决定是否立即扫描。设置完成后服务自动切换到正常模式。

也可以在上方表单中预先填写「访问密码」，容器首次启动即生效，首次设置页会显示访问密码已设置。

首次设置只接受来自宿主机或同一局域网设备的访问；通过反向代理或公网打开时，页面会提示改用局域网地址完成设置。

### 硬件转码

镜像自带 FFmpeg 与 Mesa VAAPI 驱动，默认仅使用软件转码。需要 AMD / Intel 硬件转码时，请手动编辑容器编排，透传 `/dev/dri/renderD128` 渲染节点并补充渲染组 GID，详细步骤见官方部署文档。
